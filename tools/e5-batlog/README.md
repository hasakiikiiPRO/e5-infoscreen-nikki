# e5-batlog：电量与深睡记录

每 10 分钟（cron `*/10 * * * * /usr/sbin/e5-batlog`）记一行到 `/mnt/e5-data/batlog.csv`：时间、电量%、开路电压、充放电、是否插电、深睡次数/累计秒数、低功耗模式、休眠服务状态。只在系统醒着时顺手记，不会唤醒系统。

休眠失败时内核报的原因（哪个设备挡住、SDIO/Wi-Fi 报错等）连同当时的 Wi-Fi / 蓝牙 / 唤醒锁 / 屏幕状态，追加到 `/mnt/e5-data/batlog-suspend.log`。系统日志在内存里，没电关机就没了，这两个文件在数据分区上，能留下来。

**11-21 那一晚的记录**（低功耗 1.2、拔电）：14:15 起 5 小时深睡 173 次、约 65% 时间在睡，平均约 44 mA（每 1–2 分钟被唤醒一次）；19:10 屏幕被点亮一次后再也没睡成功，约 110 mA，次日 04:40 电池耗尽关机。当时还没有失败原因记录，所以 19:10 之后为什么睡不下去没查到。
