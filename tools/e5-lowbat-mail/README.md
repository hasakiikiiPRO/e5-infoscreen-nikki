# e5-lowbat-mail：电量低发邮件

没插电、电量**低于 10%** 时发一封邮件，**低于 5%** 再发一封（「马上要关机了」），
写明电量、电压、热点上连着几台设备、低功耗模式开没开。插上充电或回到 15% 以上后重新计数。
cron 每 5 分钟检查一次（只在系统醒着时；深睡中的 E5 由基带约每 6 分钟唤醒一次）；
没网发不出去的，下一次接着发。

    tools/e5-lowbat-mail/install.sh 授权码文件 [收件人] [发件QQ邮箱]   # 默认都是 2465335064@qq.com

发件用 QQ 邮箱 SMTP（smtp.qq.com:465），密码是 QQ 邮箱的**授权码**，只存在 E5 的
`/etc/e5-lowbat-msmtprc`（仅 root 可读，不进 git）。试发一封：`e5-lowbat-mail --test 8`。
